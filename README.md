#Amazon-clone

A simple Amazon clone built using HTML and CSS, designed to mimic the layout and basic structure of the Amazon homepage. It features a responsive header, navigation bar, product listings, and footer. Ideal for beginners to practice front-end web development and improve UI/UX design skills.
